# 스킬 이펙트 세트와 전체 대응표 — 2026.10.17.2

편집기와 일반 전투 엔진을 확인한 결과, 재료 카탈로그 50종에 SP·부활 및 이전 저장 호환 항목을 더해 총 **62종**이 실행됩니다. 대상 20종, 발동 시점 22종, 추가 조건 13종을 함께 확인했습니다. AI가 이 모든 재료를 제한 없이 생성한다는 뜻은 아닙니다. 기존 세대·역할·슬롯 예산 제한은 그대로 적용합니다.

이전 버전의 12종 연출을 단순히 색만 바꾸면 흡혈·연쇄·표식·지속 효과·자원 지원의 의미가 사라집니다. 이번 버전은 **시전 → 전달 → 적용 → 지속 표시 → 종료**를 조합합니다. 서로 다른 모든 스킬 조합마다 애니메이션 파일을 만들지 않고, 실제 엔진 이벤트와 상태를 따라 모양·궤적·타수·상태 문양을 합성합니다.

## 설계 원칙

- **전달 방식:** 자신 대상은 자기 주변, 원거리는 이동 투사체, 분산은 실제 타격 대상, 연쇄는 직전 피격 대상에서 다음 피격 대상으로 연결합니다. 전체·집단 대상에는 범위 파문을 더합니다.
- **시간과 타수:** 다단히트·분산·연쇄의 실제 피해 이벤트에 타격 순번을 붙여 간격을 두고 연출합니다. 전투의 실제 피해 계산 시점을 뒤로 미루는 조정은 아닙니다. 효과 연출과 피해 숫자를 순서대로 보여주고 마지막 타격 후 결과 화면을 띄웁니다.
- **지속 효과:** 독·화상·감전은 실제 피해 주기에 작게 분출하며 다시 투사체를 쏘지 않습니다. 지속 회복도 실제 회복 주기에 빛납니다. 지연 피해는 준비 표시·남은 시간과 실제 폭발을 구분합니다.
- **상태 구분:** 피해 감소·횟수형 무효·무적·생존, 강화·약화·정화·해제, 기절·빙결·속박·봉인·회복 금지를 서로 다른 문양으로 표시합니다. 아이콘은 색 이외의 구별 수단이기도 합니다.
- **연계·자원:** 흡혈 회복은 피해를 준 적에서 시전자에게 돌아옵니다. SP 지원은 대상의 궁극기 버튼 쪽으로 들어갑니다. 표식·기록·각성·교체는 각각 문양과 수치를 구분합니다.
- **표시의 근거:** 지속 아이콘은 실제 상태 목록과 지연 작업 목록에서 읽습니다. 지속 시간이 끝나거나 정화·해제·사망으로 없어지면 표시도 없어집니다. 남은 시간·중첩·횟수·기록값·보호막량을 해당 효과에 맞게 표시합니다. 상세 설명은 아이콘을 터치해 확인합니다. 표식 이름 같은 사용자 입력은 글자로만 처리합니다.
- **조건의 의미:** 추가 조건이나 발동 확률을 통과하지 않은 효과에는 적용 연출을 만들지 않습니다. 발동 시점 22종은 실제 엔진의 발동 이벤트를 사용합니다. 아직 발동하지 않은 조건을 연출만으로 발동한 것처럼 만들지 않습니다.

## 편집과 확인

스킬 편집 → **발동 제한 · 연출 설정**에서 ‘효과별 자동’ 또는 구분된 목록의 연출을 선택합니다. 자동을 제외한 연출 프리셋은 **56종**입니다. 자동은 실제 효과·상태 종류·타수·캐릭터 모티프에 맞춰 조합합니다. 직접 지정한 연출에도 실제 효과를 구분하는 보조 문양이 붙습니다. 연쇄 경로·분산 대상·다단 타수·지연 폭발은 실제 효과에 맞게 유지합니다.

색상은 **효과별 기본색 / 직접 지정한 색**으로 나뉩니다. 팔레트나 색상 입력을 바꾸면 직접 지정 모드로 전환합니다. 자동 연출을 사용하면서 원하는 색을 입힐 수도 있습니다. 저장하지 않은 편집 상태에서도 미리보기가 가능합니다.

‘선택 스킬 전체 미리보기’는 한 스킬 안의 최대 5개 효과를 순서대로 보여줍니다. 빠른 확인을 위해 대기 시간을 줄이고 연속 타격은 최대 5타까지만 표시합니다. 실제 타이밍·전체 타격·최종 수치는 설정 → **연습장**에서 확인합니다. 미리보기를 다시 누르면 이전에 예약된 미리보기는 이어서 나타나지 않도록 구분합니다.

## 모바일과 검증 범위

한 전투 화면의 일시 연출 노드를 최대 96개로 제한합니다. 붐빌 때 보조 파편을 줄여 주요 문양과 투사체에 공간을 남기며, 지속 상태 표시는 대원·적별로 관리합니다. 보이는 상태 아이콘은 우선 5개, 나머지는 +숫자를 눌러 확인합니다. 기기의 동작 줄이기 설정에서는 이동과 잔상을 줄이고 짧은 적용 문양·상태 정보는 유지합니다.

연출용 정보만 추가했으며 전력 예산이나 전투 계산 규칙을 바꾸지 않습니다. 이전 엔진의 15개 세대별 전투를 숫자 기준 자료로 보관하고 새 엔진의 승패·시간·생존·피해가 그대로 일치하는지 검사합니다. 모든 62종의 프로필·실제 렌더러 연결, 실제 타수·연쇄 출발점·지연/주기 이벤트·흡혈 방향, 상태 해제, SP 목적지, 미리보기 교체와 Worker 독립 실행도 검사합니다. 이 자동 검사는 DOM·SVG·애니메이션 좌표를 확인하는 범위이며 실제 Android 화면·프레임 속도나 실제 AI API 응답을 확인한 것은 아닙니다.

## APK 설치 전 연출 확인

함께 제공한 maker-effect-gallery-2026.10.17.2.html을 브라우저로 열면 효과 62종을 선택하고 연출·색상·상태·능력치를 바꿔 볼 수 있습니다. 복합 스킬 예시 버튼도 있습니다. 외부 서버나 AI 연결 없이 동작하며 실제 앱의 연출기를 포함합니다. 이 파일은 전투 수치를 시험하는 시뮬레이터가 아니라 연출 검토용입니다.

## 설치·소스 반영

기존 메이커 전투 테스트 앱 위에 APK를 설치합니다. 패키지와 서명은 그대로이며 Android 업데이트 번호는 12 → 13입니다. 소스 ZIP을 풀어 안쪽 프로젝트 폴더의 내용을 저장소 루트에 반영합니다. 자동 패치에는 www/index.html과 version.json을 같은 커밋으로 반영해야 합니다. APK만 릴리스에 첨부하는 것으로 웹 패치가 갱신되지는 않습니다. 비공개 업데이트 주소는 기존 example/maker-combat-test의 main을 유지합니다.
