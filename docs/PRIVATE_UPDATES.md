# 내 비공개 GitHub에서 테스트 앱 자동 패치

앱 버전: 2026.10.16.6
대상: example/maker-combat-test / main / www/index.html

## 처음 한 번 할 일

1. 새 APK를 기존 「메이커 전투 테스트」 위에 설치합니다. 기존 앱을 삭제하지 마세요. 패키지 이름과 테스트 서명은 동일합니다.
2. 함께 받은 업로드 ZIP을 압축 해제합니다. 안의 파일·폴더를 저장소 최상위에 덮어 올립니다. 저장소의 Code 첫 화면에 www 폴더가 있어야 하고, 그 안에 index.html이 있어야 합니다. ZIP 자체를 올리는 것으로는 패치되지 않습니다.
3. 앱의 설정 → 앱 업데이트를 엽니다. 개발자용 설정에 본인의 GitHub 읽기 전용 토큰을 입력합니다. 토큰은 해당 저장소만 선택하고 Contents: Read-only 권한을 부여한 fine-grained 토큰을 사용하세요. 토큰을 파일이나 채팅에 적지 마세요.
4. 「새 버전이 있으면」을 「조용히 받아서 다음 실행에 적용」으로 선택하고 「저장하고 확인」을 누릅니다.
5. 이번 업로드 파일과 APK는 같은 버전이므로 「이미 최신 테스트 버전」 안내가 나오면 정상입니다.

저장소/브랜치/경로는 앱에 미리 지정했습니다. 토큰은 기기 설정에만 저장되며 APK·소스 ZIP에는 포함되지 않습니다.

## 다음 버전부터

새 테스트 패치의 www/index.html을 같은 저장소의 같은 경로에 올리면 됩니다.
이 파일에는 전투 모듈이 모두 포함되어 있습니다. 전용 채널 표시와 더 높은 버전 번호가 있어야 받아들입니다.
예: 2026.10.16.2 → 2026.10.16.3. 번호를 올리지 않은 수정이나 예전 원본 HTML은 적용되지 않습니다.
새 기능을 수정할 때 「비공개 저장소 자동패치용 업로드 묶음도 만들어줘」라고 요청하면 됩니다.

앱을 열고 약 5초 뒤, 앱으로 다시 돌아올 때, 켜 놓은 동안 5분마다 확인합니다. 인터넷이 연결되어 있고 토큰이 유효해야 합니다.
새 버전을 받았다는 안내가 나오면 앱을 최근 앱 목록에서 완전히 종료하고 다시 열어 적용하세요. 전투 중 강제로 다시 시작하지 않습니다.
확인을 끄면 자동으로 받지 않으며 「저장하고 확인」으로 수동 확인할 수 있습니다.

## 안 될 때

- 저장소 첫 화면에 www 폴더가 없고 ZIP 파일만 있다면 압축을 풀어 올리세요.
- 저장소/브랜치/경로: example/maker-combat-test / main / www/index.html.
- 토큰의 만료일과 선택한 저장소, Contents 읽기 권한을 확인하세요.
- 「전용 테스트 패치가 아님」은 이전에 받은 일반 소스 HTML을 올렸거나 전용 표시가 없는 파일을 올렸다는 뜻입니다. 이번 묶음의 www/index.html로 교체하세요.
- 같은 버전은 다시 받지 않습니다. 다음 파일의 버전 번호가 더 높아야 합니다.
- 설정의 이전 버전 되돌리기와 설치 버전으로 돌아가기를 사용할 수 있습니다. 기존 초기화/실행 실패 복구 경로를 유지합니다.

## 패치 범위와 검증

이 기능은 게임 HTML과 그 안에 포함한 JavaScript·스타일을 업데이트합니다. Android 권한, 네이티브 플러그인, 앱 아이콘 같은 변경에는 새 APK 설치가 필요합니다.

고정된 비공개 저장소의 GitHub API만 사용합니다. 공식 공개 채널로 대체 연결하지 않습니다.
Git blob의 SHA-1을 원본 바이트로 검증하며, 전용 채널 표식과 버전을 검사한 뒤 저장합니다.
기존 전투 검사와 업데이트 모의 응답 검사 총 25개 통과. APK 서명/정렬 확인.
실제 비공개 GitHub 다운로드는 사용자 토큰이 없어 확인하지 못했고, Android 실기기 설치/실행도 미검증입니다.

## 개발자용 빌드

기존 빌드 명령에 --build 2026.10.16.3를 지정하면 다음 APK와 artifacts/private-update/www/index.html 및 version.json을 생성합니다.
--private-repo로 빌드 대상 저장소를 지정할 수 있으며 기본값은 위 개인 테스트 저장소입니다.
GitHub에 올릴 배포 HTML은 artifacts/private-update/www/index.html입니다. 개발 원본 www/index.html을 그대로 올리면 채널 표식이 없어 거부됩니다.
