# 2026.10.16.3 — 스킬 편집 및 이미지 UX

- 패시브 발동 시점에 따라 간격, 일반 공격 횟수, 적중 횟수, HP 비율, 표식 이름·중첩 중 필요한 입력만 표시합니다. 효과 추가 조건도 HP, 표식, 인원 조건별로 필요한 입력만 표시합니다. 효과 수치 및 타수 이름도 효과 종류와 계산 기준에 맞게 표시합니다.
- AI에게 컨셉 및 세 슬롯 역할·연계를 먼저 구상하고 지원되는 효과로 JSON을 작성하도록 요청합니다. 선택 필드 누락은 기본값으로 보충하고 숫자 문자열은 변환합니다. 범위 초과, 알 수 없는 효과·대상·조건, 잘못된 조합은 직전 문제를 전달해 다시 생성합니다. 최초 1회 + 재생성 최대 5회(총 6회 요청)입니다. 인증·통신 오류는 중단합니다. 최종 실패는 기존 스킬·편집 초안을 유지합니다. 수동 입력에는 자동 수치 보정을 적용하지 않습니다.
- AI 대기 및 스킬 내부 검사에 움직이는 점 표시를 사용합니다. 캐릭터 생성 후 잘못된 스킬이 발견된 경로도 같은 생성 함수를 사용합니다.
- 장비 아래에 패시브, 액티브, 필살기를 각각 별도 카드로 표시합니다. 각 카드에서 해당 슬롯 편집 위치로 이동할 수 있습니다.
- 장비 이미지 생성 버튼 오른쪽에 스킬 이미지 생성 버튼을 추가합니다. 세 행 목록에서 스킬별 NAI 프롬프트를 입력해 정사각형 아이콘을 생성합니다. 현재 그림 AI 공급자·스타일 설정을 사용합니다. 내부 확인은 목록 초안에만 반영하고 내부 ×는 해당 미리보기를 폐기합니다. 외부 완료는 확인 후 저장, 닫기·×는 확인 후 초안 전체를 폐기합니다. 생성 중 닫은 창의 늦은 응답은 반영하지 않습니다. 아이콘은 캐릭터의 skillIcons에 저장되어 스킬 재생성·정규화 때 보존되고 이미지 로딩·백업 목록에도 포함됩니다.
- 스탠딩 사용 스위치는 캐릭터별 useStanding에 저장합니다(이전 데이터 기본값 켜짐). 끄면 캐릭터/장착 스킨의 스탠딩 표시는 스킨 상반신 → 기본 상반신 순으로 대체하며, 없으면 미등록 표시합니다. 표정도 상반신 표정을 사용하고 전신으로 되돌아가지 않습니다. 미리 그리기에서 비활성 캐릭터의 전신 생성은 제외합니다. 저장된 원본은 삭제하지 않습니다.

검증: 자동화 테스트 49개(모의 AI·DOM 포함). 실제 Android 기기 UI 및 실제 유료 AI 응답·이미지 생성은 검증하지 않았습니다. APK는 공식 네이티브 셸의 dex를 보존하고 수정한 웹 자산을 포함해 재서명합니다. 이전 개인 테스트 앱과 동일 패키지·서명 및 비공개 업데이트 채널을 사용합니다.
