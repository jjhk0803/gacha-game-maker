# 전투 연출 표시 오류 수정 — 2026.10.17.3

## 확인한 원인

이번 문제의 핵심은 APK에 파일이 빠진 것이 아니라 **표시할 부모 요소를 잘못 찾은 것**이었습니다. 로비의 배너 버튼과 일반 전투 화면이 모두 `.bt`라는 클래스를 사용합니다. 전체 문서에서 첫 번째 `.bt`를 찾으면 로비 버튼이 선택되어 전투 이펙트·컷인·결과창·연습장 설정이 그 안에 들어갈 수 있었습니다. 전투 화면은 그 위의 별도 덮개이므로 연출이 안 보이거나 가려졌습니다. 코드·DOM 존재만 검사했던 이전 검증으로는 이 문제를 놓쳤습니다.

추가로 확인한 문제는 다음과 같습니다.

- ‘작은 띠’ 설정은 컷인을 표시하지 않고 종료했습니다.
- 기본 애니메이션 API가 없으면 이펙트에 마지막 프레임의 투명도 0을 적용했습니다.
- 일반 공격의 속성색은 CSS 변수인데, 연출기는 6자리 색상값만 받아 같은 기본색으로 바꿨습니다.
- 내부 채움이 15%로 옅고 선·발광 위주인 데다, 초반에 빨리 진행되는 이징 때문에 효과가 흐리고 짧게 보였습니다.
- 여러 재료가 비슷한 문양과 움직임을 공유하는데 선택지는 56개여서 실제 차이에 비해 목록이 과도했습니다.

## 바뀐 동작

1. 일반 전투의 모든 표시 경로를 `#ov > .bt`로 한정했습니다. 로비와 이름이 같아도 전투 덮개 안에만 이펙트·컷인·결과를 붙입니다. 연습장 표시 설정도 같은 화면에 적용합니다.
2. 큰 컷인·작은 띠 컷인을 모두 구현했습니다. 띠의 진입/퇴장, 캐릭터 확대 이동, 이름 이동을 각각 재생합니다. 그림이 없어도 기본 상반신/미등록 그림과 스킬 이름으로 재생합니다. ‘끄기’ 설정은 유지합니다.
3. 기기의 동작 줄이기에서는 짧고 단순한 페이드 컷인을 사용합니다. 기본 애니메이션 API가 없거나 실패하면 프레임 갱신 방식으로 이동을 대체합니다. 이펙트를 처음부터 투명하게 처리하지 않습니다.
4. 컷인 중 전투 시간·쿨타임·SP 진행 정지와 종료 후 재개를 유지합니다. 연습장의 수동 정지 상태는 별도입니다.
5. 공격은 참격 곡선, 별 모양 충격, 불꽃 덩어리, 얼음 결정, 꺾인 번개 선으로 표현합니다. 직선 피해마다 같은 문양을 겹쳐 띄우는 방식은 줄였습니다. 선을 굵게 하고 내부를 채우며, 흰 중심과 색상 외곽으로 형태를 구분합니다. 대부분의 표시 시간 동안 선명한 상태를 유지한 뒤 사라집니다.
6. 선택 목록을 **대표 프리셋 24개 + 효과별 자동**으로 정리했습니다. 62종 스킬 재료의 기능과 자동 조합은 유지합니다. 목록에서 빠진 기존 연출이 저장되어 있으면 ‘기존 저장 설정’으로 표시하여 다른 스킬을 편집하는 것만으로 값이 바뀌지 않게 합니다.
7. 속성별 일반 공격 색상을 실제 CSS 색상으로 해석합니다. 기본색 모드의 불꽃·얼음·번개 등에도 구분되는 기본색을 적용합니다.
8. 전투 화면 위에 **테스트 2026.10.17.3**을 표시합니다. APK 설치 후 이 문구로 실제 실행 중인 게임 화면 버전을 확인할 수 있습니다.

## 확인 방법

기존 메이커 전투 테스트 앱 위에 새 APK를 설치하고 설정 → 연습장으로 들어갑니다. 전투 위쪽에 ‘테스트 2026.10.17.3’이 있는지 확인합니다. 궁극기 SP가 차면 수동으로 눌러 컷인과 전투 정지를 확인할 수 있습니다. 설정 → 화면·연출에서 컷인을 ‘작은 띠만’으로 바꿔도 컷인이 나옵니다. ‘끄기’라면 나오지 않습니다.

함께 제공하는 `maker-render-preview-2026.10.17.3.html`을 브라우저로 열면 새 대표 연출과 큰/작은 컷인을 APK 설치 전에도 볼 수 있습니다. 미리보기는 연출 확인용이며 실제 수치·대기는 연습장에서 확인합니다.

## 검증 범위

기존 자동 검사에 로비와 전투의 이름 충돌, 작은 컷인의 실제 부모, 애니메이션 API 부재/오류, 색상 해석 회귀 검사를 추가했습니다. 실제 Chromium에서 390×844와 360×740 화면으로 실행하여 다음을 확인했습니다.

- 전투 안에서 보호막·회복·강화·표식·기록·빙결이 실제로 보이는지, 선명한 시점의 투명도·크기·서로 다른 SVG 형태
- 참격·불꽃·얼음·번개의 서로 다른 타격 형태와 실제 표시
- 큰/작은 컷인의 이동, 동작 줄이기의 페이드, 애니메이션 API가 없는 경우의 대체 이동
- 컷인 중 시간 정지와 재개, 종료 후 요소 정리
- 원본/전달 APK의 웹 코드 일치, 네이티브 코드 보존, 이전 테스트 앱과 같은 서명 및 업데이트 번호 13 → 14

브라우저 실행은 실제 화면을 렌더링하는 검사지만 Android 실기기의 WebView·GPU 성능을 검사한 것은 아닙니다. 실제 AI 서비스 응답도 이번 환경에서 호출하지 않았습니다. 이전 엔진 대비 15개 기준 전투의 계산 결과 일치 검사는 유지했습니다.

## 소스 반영

ZIP 안쪽 프로젝트 폴더의 내용을 비공개 저장소 루트에 반영합니다. 웹 자동 패치를 배포하려면 `www/index.html`과 `version.json`을 함께 갱신해야 합니다. APK를 릴리스 첨부 파일에만 올리는 것으로 웹 패치가 바뀌지는 않습니다. 기존 비공개 업데이트 채널과 데이터 형식은 유지합니다.
