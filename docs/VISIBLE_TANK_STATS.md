# 탱커 기본 능력치로 전환 — 2026.10.18.1

> 2026.10.18.2에서 상세 STATUS 아래 기본 수치 안내 문구는 제거했습니다. 기본 스탯 계산과 편집 입력은 유지합니다.

탱커에게 전투 계산 중 체력 1.6배·방어력 1.5배를 붙이던 역할 보너스를 제거했습니다. 이제 캐릭터에 저장된 기본 체력·방어력 자체가 높습니다.

## 새 탱커 생성

| 생성 기준 | 이전 | 현재 |
|---|---:|---:|
| 체력 | 1500 | 2400 |
| 방어력 | 85 | 128 |
| 공격력 | 85 | 85 |

기준 수치는 R 등급의 중심값입니다. 체력은 R/SR/SSR 각각 1/1.04/1.12, 방어력은 1/1.1/1.12의 기존 희귀도 생성 계수를 사용하고 ±5% 편차를 유지합니다. 체력은 10 단위, 방어력은 정수로 반올림합니다. 예를 들어 편차가 0인 SSR 탱커는 기본 체력2690·방어력143입니다. 이는 저장되는 원본 숫자이며 전투에서 탱커라는 이유로 다시 곱하지 않습니다.

일반 생성기(sysStats)와 AI 응답 정리기(cleanChar0)가 같은 생성 기준을 사용합니다. AI가 예전 범위의 낮은 체력·방어력을 보내더라도 신규 탱커에는 시스템의 높은 기본 능력치가 저장됩니다. AI 요청에도 새 탱커 수치 범위를 안내합니다. 공격형·지원형의 생성 기준은 변경하지 않았습니다.

## 기존 캐릭터

업데이트 또는 예전 백업 불러오기 시, 이전하지 않은 탱커의 기본 체력을 1.6배·방어력을 1.5배로 한 번 바꾸어 저장합니다. 예: 1500/85 → 2400/128. 이전 수치는 캐릭터의 baseStatsMigration에 보관하고, baseStatsVersion:1 표시를 캐릭터별로 저장합니다. 이 표시는 백업에도 포함되므로 재접속·프로젝트 이동·새 버전 백업 재불러오기 시 중복 상향하지 않습니다.

공격형·지원형도 버전 표시만 부여합니다. 이후 직접 탱커로 역할을 바꾸어도 숨은 자동 보정은 하지 않습니다. 사용자가 체력1000·방어력100인 탱커를 직접 저장하면 그 기본 수치를 사용합니다. 캐릭터의 스킬, 장비 연계, 보유 레벨·돌파·스킬 강화 재료는 이 이전으로 변경하지 않습니다.
