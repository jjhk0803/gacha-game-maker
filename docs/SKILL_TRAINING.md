# 스킬 성장 — 2026.10.17.14

## 사용하는 방법

캐릭터 상세 → 장비·스킬에서 **스킬 공통 레벨 강화**를 누릅니다. 재료·재화 비용과 세 스킬의 강화 전후 설명을 확인한 뒤 확정합니다. Lv.1부터 시작하며 공통 Lv.7까지 패시브·액티브·궁극기가 함께 성장합니다. Lv.7에서는 각 스킬 블록의 **전문화 강화**로 선택한 슬롯만 1~3단계 더 강화합니다. 대기 시간이나 별도 시설·재료 등급은 추가하지 않았습니다. 미보유 캐릭터는 획득 후 강화할 수 있습니다.

스킬 편집기는 기본 설계를 편집합니다. **SP 회복·피해 감소·적 공격속도 감소·치명타 확률 증가의 효과량은 Lv.10 기준**, 나머지는 Lv.1 기준입니다. 상세 화면의 설명과 일반 전투·연습장은 소유한 캐릭터의 실제 성장치를 적용합니다. 스킬 편집·AI 재생성 후에도 공통 레벨과 해당 슬롯의 전문화는 유지합니다. 캐릭터 기본 능력치를 올리는 시스템과 별개입니다.

## 메이커에 적용한 성장

원본 설계는 저장한 그대로 두고, 전투 시작 때 성장 보너스를 한 번 계산합니다. 장비 고유 효과와 일반 장비 강화는 그 위에 기존 방식대로 적용합니다. 성장만으로 장비의 연계가 끊기거나 붉은 경고가 생기지 않습니다. 실제 스킬 설계 변경·리롤 시 연계가 중지되는 기존 규칙은 유지합니다.

| 성장 항목 | Lv.1 | Lv.4 | Lv.7 | 전문화 1 | 전문화 2 | 전문화 3 |
| --- | ---: | ---: | ---: | ---: | ---: | ---: |
| 직접/지속 피해·회복·보호막의 수치 | 100% | 112% | 125% | 132% | 140% | 150% |
| 일반 능력치 강화·약화 | 100% | 104.8% | 110% | 112.8% | 116% | 120% |
| 공격속도 증가·치명타 피해 계열 | 100% | 102.4% | 105% | 106.4% | 108% | 110% |
| 치명타 확률 증가 (입력값=Lv.10) | 66.67% | 77.78% | 88.89% | 92.59% | 96.3% | 100% |
| SP 회복·피해 감소·적 공격속도 감소 (입력값=Lv.10) | 50% | 66.67% | 83.33% | 88.89% | 94.44% | 100% |
| 정화·해제 단독 반복 스킬의 대기시간 | 100% | 96% | 92% | 91% | 90% | 88% |
| 정화·해제 제거 개수 | 기존값 유지 | 유지 | 유지 | 유지 | 유지 | 유지 |

| 궁극기 전투 시작 SP | 0 | 3.33 | 6.67 | 7.78 | 8.89 | 10 |

Lv.2·3·5·6의 일반 위력 배율은 각각 104%·108%·116%·120%입니다. 정화·해제 대기시간 배율은 해당 단계에서 99%·98%·95%·94%입니다. 이 배율은 원본 값에 곱하는 값이며 퍼센트포인트 증가가 아닙니다. 180% 공격은 Lv.7에서 225%, 전문화 3에서 270%가 됩니다.

정화·해제 개수는 고정합니다. 단독 반복형은 기존 최대 12% 주기 단축을 유지하고 복합형은 동반 효과도 정상 성장하되 주기 단축을 최대 2%·0.2초로 제한합니다. 평타·피격 필요 횟수는 고정입니다.

피해·회복·보호막은 위력만 최대 50% 성장합니다. SP 회복·피해 감소·적 공격속도 감소는 원본 입력값의 50%→100%, 치명타 확률 증가는 ⅔→100%로 성장합니다. 인접 레벨마다 같은 양이 증가하며, 구형 직접 효과와 능력치 강화/약화 형식에 같은 규칙을 적용합니다. 해당 효과는 기존 미세 성장이나 30% 소프트캡 곡선을 중복 적용하지 않습니다. 입력값 자체의 생성 제한과 엔진 최종 합산 제한은 유지합니다.

나머지 일반 능력치·공격속도 증가·치명타 피해·회피 등은 기존 곡선을 유지합니다. 게이지·흡혈·부활량·쿨타임 조작은 기존 소폭 성장, 제어는 최대 0.1초, 면역·횟수형 방어·표식 등은 최대 0.25초만 연장합니다. 확률·횟수·대상 수는 늘리지 않습니다. 궁극기 시작 SP는 유효 레벨마다 0→10으로 성장하며 사용 비용은 100입니다.

스킬 설명·입력·강화 전후는 소수점 둘째 자리까지 반올림합니다. 원본 정밀도는 유지합니다. 실제 효과가 달라지지 않는 전문화는 버튼을 비활성화하고 확인 시 재료 소비도 막습니다. 이번 변경의 정확한 성장표는 [새 성장 규칙](SKILL_GROWTH_CURVE.md)을 참고하세요. [이전 전수 조사](SKILL_GROWTH_AUDIT.md)는 .13 버전의 기록입니다.

### 무적 기본 제한과 성장

무적은 Lv.1에서 입력 지속의 절반·최대 2초, 최소 재사용 18초로 시작합니다. Lv.10(공통 Lv.7 + 전문화 3)에서 Lv.1 실제 지속의 1.5배·최대 3초, 최소 재사용 17초까지 점진적으로 성장합니다. 원본 9초 무적은 2초 → 3초, 원본 1초 무적은 0.5초 → 0.75초입니다. 원래 18초보다 긴 쿨타임은 총 1초만 단축합니다.

같은 대상에게는 마지막 적용 시점의 성장 단계에 맞춘 재적용 제한을 둡니다. 다른 시전자·즉시 준비·해제·스킬 교체로 이를 단축하지 못합니다. 상시 패시브도 무한 지속되지 않고 장비 효과로 단계별 최대 지속을 넘지 못합니다. 궁극기도 최소 재발동 간격을 적용하며 SP 100이 별도로 필요합니다. 최초 발동 대기는 늘리지 않습니다.

무적은 별도의 성장 규칙을 사용합니다. 직접 편집창은 원본 입력값과 제한 설명을 보여 주고 상세/강화 비교에는 실제 적용값을 보여 줍니다. 단계별 표와 검증 범위는 [무적 성장](INVINCIBILITY_GROWTH.md)을 참고하세요.

## 재료와 비용

기존 `wmat` 재고를 그대로 **스킬 교본**으로 사용합니다. 기존 캐릭터·장비 단계·재료 개수는 보존합니다. 재료 던전·상점·교환·파견·보상도 같은 재료를 계속 줍니다. 기존 저장의 재료 이름은 한 번 전환하고 이후 사용자가 용어를 수정할 수 있습니다.

## 생성 검사와 저장 호환

스킬 생성은 기존 세대별 **Lv.1 원본 설계**를 기준으로 검사합니다. 성장했다고 AI가 투자 효과를 상쇄하도록 원본을 너프하지 않습니다. 장비의 장착 전후 검사는 같은 스킬 성장 상태를 양쪽에 적용합니다. 강화를 했다는 이유로 적을 즉시 강하게 만들지 않습니다.

성장은 플레이어 보유 정보의 `skillTraining: {rank, mastery:{passive,active,ultimate}}`에 저장합니다. 구형 저장은 Lv.1·전문화 0으로 이전하며 원본 스킬을 백업·교체하지 않습니다. 강화는 재료 확인 → 전후 비교 → 사용자 확정 후 이루어집니다. 오래된 확인창·중복 확정·재료 부족에서는 이중 소모하지 않습니다. 진행 중인 전투는 시작 시점의 상태를 유지하고 다음 전투에 성장이 반영됩니다.
