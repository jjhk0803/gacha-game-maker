# 전용장비 고유 패시브 — 2026.10.17.9

## 기존 강화와 새 효과

기존 전용장비 해금·강화 비용과 단계는 그대로입니다. 단계당 HP +3%, 공격력 +6%, 기존 공격 스킬 위력 +5% 계산도 유지했습니다. 추가한 고유 효과는 **패시브 또는 액티브의 효과 하나를 강화하는 장비 패시브 1개**입니다. 장비 1단계 해금부터 작동하고, 이후 단계에서 고유 효과 수가 늘어나지는 않습니다.

기존 캐릭터도 처음 장비 화면을 열거나 전투에 들어갈 때 현재 스킬을 분석해 적용 가능한 기본 고유 효과를 자동으로 구성합니다. 이 과정은 AI 호출 없이 작동합니다. 장비가 잠겨 있으면 미리 볼 수 있지만 전투에는 적용하지 않습니다. 장비 효과가 한 번 구성된 뒤에는 스킬 변경에 맞춰 임의로 다시 생성하지 않습니다.

궁극기는 연계 대상으로 선택할 수 없습니다. 스킬 원본 수치를 덮어쓰지 않고 실제 발동 시 해당 패시브·액티브의 지정된 효과에만 보정을 넣습니다. 공격력 버프처럼 원래 다른 행동에도 영향을 주는 효과의 파급은 기존 전투 규칙을 따릅니다.

## 캐릭터성을 살리는 옵션

현재 저장된 두 스킬에 적용 가능한 후보를 분석해 하나만 자동 선정합니다.

| 옵션 | 동작 |
| --- | --- |
| 표식 추가 중첩 | 표식을 한 번에 1중첩 쌓던 경우 2중첩 적용. 기존 최대 중첩은 유지 |
| 연속 공격 타수 추가 | 해당 연속 공격에 1타 추가. 궁극기에는 적용하지 않음 |
| 지속 시간 연장 | 연계된 강화·약화·보호막·지속 피해/회복 등의 지속 시간 연장 |
| 위력 증가 | 연계된 피해·회복·보호막·버프 등 한 효과의 수치 증가 |
| 저체력 대상 강화 | 대상 HP가 50% 이하일 때 연계 효과 강화 |
| 무작위 대상 추가 | 무작위 대상 효과의 적용 인원 1명 추가. 적 최대 5명/아군 최대 4명 |
| 해제 수 추가 | 해당 정화·해제 효과가 제거하는 상태 1개 추가 |

표식·연타·지속 효과처럼 특징이 뚜렷하면 그 특징을 우선 선택합니다. 관련 효과가 없는 캐릭터에게 표식이나 추가 스킬을 새로 부여하지 않습니다. 두 스킬 모두 적합한 강화 지점이 없으면 구성 불가를 안내하고 기존 강화 보너스만 유지합니다.

## 편집과 AI 생성

캐릭터 → 장비·스킬 → 장비 블록의 **고유 효과 편집 · AI 생성**에서 엽니다. 패시브와 액티브를 함께 분석해 어느 스킬의 어떤 효과를 강화할지 생성 과정에서 자동으로 결정합니다. 사용자는 연계 스킬이나 강화 종류를 선택하지 않습니다. 선정된 스킬과 효과는 읽기 전용으로 표시합니다. 사용 여부 체크박스 없이 해금 후 항상 적용하며, 연계 스킬 변경에 따른 안전 중지는 유지합니다. 이전 버전에서 사용을 꺼 둔 정상 효과도 적용됩니다.

- 자동 선정된 효과의 이름과 수치를 편집할 수 있습니다.
- ‘현재 스킬 분석으로 자동 구성’은 AI 없이 새 초안을 구성합니다.
- ‘AI로 고유 효과 구성하기’에서 원하는 캐릭터성을 입력할 수 있습니다. 비우면 현재 캐릭터·장비·두 스킬의 컨셉을 참고합니다.
- AI는 지원되는 연계 옵션 목록에서 하나만 선택합니다. 잘못된 스킬·옵션·수치는 실패 사유를 남기고 최대 5회 시도합니다. 강한 수치형 옵션은 낮춰 재검사합니다.
- 진행 단계와 경과 시간·움직이는 점, 실패 기록, 작업 중단을 표시합니다. 창을 닫거나 중단한 뒤 도착한 응답은 저장하거나 창을 다시 열지 않습니다.
- AI 생성 결과는 초안입니다. **고유 효과 검사·저장**을 눌러야 실제 장비에 반영합니다. 직접 편집한 값은 허용 범위 안에서 그대로 검사·저장하고 과성능은 경고합니다.

## 스킬 리롤과 붉은 알림

연계된 스킬의 새 결과를 **저장했을 때** 고유 효과를 자동으로 비활성화합니다. 생성 초안만 보고 취소한 경우 기존 스킬과 장비는 유지됩니다.

- 같은 스킬이 실제로 다시 생성되었다면 결과 수치가 우연히 같아도 저장 시 연결을 무효화합니다.
- 수동 수치·발동 조건·효과 구성 변경도 감지합니다.
- 이름·그림·연출색만 바꾸거나, 연계하지 않은 다른 스킬/궁극기를 바꾸는 경우에는 유지합니다.
- 장비 블록에 붉은 테두리·불빛과 ‘재생성 필요’를 표시합니다.
- 오른쪽 위 **!**를 누르면 연계 스킬 변경과 장비 옵션 재생성 안내가 뜹니다. 다른 곳을 누르면 안내가 닫힙니다.
- 기존 해금·강화 단계와 스탯 보너스는 유지하고, 새 고유 효과만 중지합니다. 진행 중인 일반 전투에도 고유 효과 중지를 반영합니다.
- 새 고유 효과를 구성·저장하면 현재 스킬에 다시 연결하고 붉은 알림을 해제합니다. 이전 수치로 되돌리기만 해서는 자동으로 재활성화하지 않습니다.

불러온 저장 데이터도 실제 스킬과 연결 정보가 일치하는지 검사합니다. 오래된/무효한 연결 때문에 기존 게임 데이터가 기본값으로 초기화되지 않는 회귀 검사를 추가했습니다.

같은 세대·캐릭터·스킬·능력치·장비 단계에서 고유 효과의 유무만 비교합니다. 레벨 1/30/70 × 적 구성 3종 × 난수 3종으로 27쌍, 총 54전투입니다. 승패·생존·피해 진행도·승리 시간의 파티 종합 점수 비율이며, 순수 피해량 배율은 아닙니다.
