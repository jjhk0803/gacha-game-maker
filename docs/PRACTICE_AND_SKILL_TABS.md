# 2026.10.16.6 — 스킬 탭·스탠딩 도움말·연습장

## 스킬과 이미지 편집

- 장비탭에서 누른 슬롯을 선택한 상태로 스킬 편집창을 엽니다. 상단 패시브 / 액티브 / 궁극기 탭으로 전환하며 다른 슬롯의 미저장 입력도 보존합니다. AI 스킬 생성·검사·저장은 현재 선택한 슬롯 하나에만 적용합니다. 자세한 진행·중단·복구 동작은 SELECTED_SKILL_GENERATION.md를 참고하세요.
- 스킬 이미지의 세 행 목록 팝업에서 상단 ×를 제거했습니다. 하단 완료·닫기는 확인 후 작동합니다. 개별 이미지 미리보기의 ×는 해당 미리보기를 폐기하고 목록으로 돌아가는 기존 동작을 유지합니다.
- 새 아이콘 프롬프트는 캐릭터 설정·외형·무기와 선택한 스킬 이름·설명·효과를 참고합니다. 글 AI가 있으면 컨셉 태그를 구성하고, 없거나 실패하면 로컬의 컨셉·효과 기반 영어 태그를 사용합니다. 기존 저장/수동 프롬프트는 유지하며 ‘캐릭터·스킬 컨셉으로 프롬프트 구성’으로 다시 작성할 수 있습니다. 프롬프트는 생성 전에 수정할 수 있습니다.
- 외형의 스탠딩 제목 우측에 ? / 스탠딩 사용 / 스위치 순으로 배치합니다. 도움말은 스크롤을 차단하지 않는 말풍선이며 바깥 클릭이나 Escape로 닫힙니다. 장착 스킨 화면에서도 같은 설정을 제공합니다.

## 연습장

설정 → 연습장 → 연습장 열기에서 시작합니다.

- 파티 1~4명: 저장한 편성과 독립된 임시 선택입니다. 보유 캐릭터는 현재 성장·전용장비·소속 보너스, 미보유는 기존 stats 함수의 Lv.1 기본값을 사용합니다. 실제 저장된 스킬을 사용하며 시작 시 자동 밸런스 재조정을 하지 않습니다.
- 허수아비 1~5마리, 기준 레벨 1~70. 탱커(def) → 딜러(atk) → 힐러(sup)를 반복 배치하고 게임 속성을 순환합니다. 각 역할의 기준 HP/ATK/DEF는 탱커 2500/110/120, 딜러 1500/180/70, 힐러 1200/90/40에 레벨 배율 1 + .06 × (레벨-1)을 곱해 반올림합니다.
- 허수아비는 행동·반응 스킬을 쓰지 않고, 받는 피해로 HP가 줄거나 쓰러지지 않습니다. HP 비례 효과는 위 기준 HP로 계산하고, 피해량은 HP 잔량으로 잘라내지 않고 그대로 집계합니다. 일반 전투는 옵션을 켜지 않으면 이 동작을 사용하지 않습니다.
- 일반 전투의 엔진·수동/자동 필살기·공격 연출·컷인을 사용합니다. 연습에는 119초 시간 제한을 적용하지 않습니다. 난수 시드 77로 다시 시작할 때 비교가 가능합니다.
- 시작 아군 HP 1~100%로 회복 스킬을 시험할 수 있습니다. 허수아비는 반격/사망하지 않으므로 아군 피격·적 처치 조건의 검증 용도에는 맞지 않습니다. 힐러 허수아비는 역할 및 능력치만 가진 비행동 모형입니다.
- 경과 시간, 캐릭터별 누적 피해·DPS·실제 회복·액티브/궁극기 사용 횟수를 표시합니다. 일시정지, 처음부터, 편성·허수아비 변경 및 종료를 제공합니다. 종료 후 직전 결과가 설정창에 남습니다.
- 행동력 차감, 전투 미션, 경험치, 재화/별/클리어 보상 처리를 건너뜁니다. 연습 속도 조절도 실제 전투 속도 설정에 저장하지 않습니다.

자동화 검증: 69개 통과(실제 전투 회귀, 엔진 허수아비, 119초 초과 유지, 탭 입력 보존, 도움말, 모의 아이콘 AI, 연습장 편성/일시정지/초기화/종료 및 진행 데이터 보존). 실제 Android 기기 화면 및 실제 유료 AI 호출은 검증하지 않았습니다.
