# 가챠 게임 메이커 (GACHA GAME MAKER)

내가 정한 세계관으로 나만의 가챠 게임을 만들어 노는 개인 제작 앱이에요. 처음 켜면 AI 키를 넣고 장르·키워드로 세계관부터 캐릭터, 스토리까지 AI가 만들어요. 키가 없으면 샘플 게임 「낙성계약」으로 바로 시작해요. 비상업 테스트 배포이고, 과금 요소는 없어요(캐시 상점도 전부 무료).

## 설치 (안드로이드)
1. [Releases](../../releases/latest)에서 `gacha-game-maker.apk`를 받아 설치해요.
2. "출처를 알 수 없는 앱" 허용을 물으면 이번 설치에만 허용해요.
3. 이후 게임 업데이트는 앱이 이 저장소에서 자동으로 받아요. 받기 전에 바뀐 점을 보여 주고 물어봐요(설정 → 앱 업데이트에서 끌 수 있어요).

## 아이폰·PC (웹 버전)
같은 주소를 PC 브라우저(크롬·엣지 등)에서 열어도 돼요. PC에서는 게임 화면이 가운데 세로로 나오고, 키보드(1~5 메뉴, Space/Enter 대사, Esc 닫기)로도 할 수 있어요. 데이터는 브라우저마다 따로 저장돼요.

앱 설치 없이 Safari에서 써요. 업데이트도 열 때마다 자동이에요.
1. 아이폰 Safari에서 **https://jjhk0803.github.io/gacha-game-maker/** 를 열어요.
2. 공유 버튼(⬆︎) → **홈 화면에 추가** → 추가.
3. 이제 홈 화면의 '가챠 메이커' 아이콘으로 열어요. (Safari 탭에서 그냥 쓰면 오래 안 열었을 때 아이폰이 데이터를 지울 수 있어요. 가끔 백업도 해 두세요.)

### 웹 버전에서 AI가 연결되지 않을 때 (중계 서버)
브라우저는 보안 규칙(CORS) 때문에 일부 AI 서비스(NovelAI 등)에 직접 연결하지 못할 수 있어요. 그럴 땐 내 전용 중계 서버를 무료로 만들어 연결해요. 직접 연결되는 서비스는 중계 서버를 거치지 않아요.
1. [Cloudflare](https://dash.cloudflare.com/sign-up)에 가입 → Workers & Pages → **Create** → **Create Worker** → 이름을 정하고 Deploy.
2. **Edit code**를 눌러 기존 코드를 지우고, 이 저장소의 [`proxy/worker.js`](proxy/worker.js) 내용을 붙여 넣은 뒤 **Deploy**.
3. 생긴 주소(`https://이름.계정.workers.dev`)를 앱의 설정 → 아이폰·웹 연결 → 중계 서버에 넣고 '연결 확인'.
- 중계 서버는 내 계정에서 돌아가고, 지정한 AI 서비스 주소로만 요청을 넘겨요. API 키가 이 서버를 지나가니 남이 만든 서버 주소는 넣지 마세요.
- ComfyUI는 웹 버전에서 https 주소만 연결돼요(Cloudflare Tunnel 등으로 열고 `--enable-cors-header` 옵션).

## PC·폰 연동 (선택)
폰과 PC(또는 아이폰)에서 같은 게임을 이어서 하고 싶으면, **내 GitHub 비공개 저장소**를 저장 공간으로 써요. 제작자 서버는 거치지 않아요.
1. GitHub에서 비공개(Private) 저장소를 하나 만들어요(예: `ggm-save`).
2. Settings → Developer settings → Fine-grained tokens에서 토큰을 만들어요. 그 저장소만 고르고, Permissions의 **Contents: Read and write**.
3. 앱의 설정 → PC·폰 연동에 `아이디/ggm-save`와 토큰을 넣어요. 다른 기기에도 똑같이 넣어요.
4. 한 기기에서 **올리기**, 다른 기기에서 **받기**. 켤 때 다른 기기의 새 데이터가 있으면 알려 줘요.
- 그림·음악·목소리도 같이 옮겨요. 바뀐 파일만 올려서 두 번째부터는 빨라요.
- API 키는 기본으로 옮기지 않아요(원하면 설정에서 켤 수 있어요).

## AI 기능과 키
- 새 캐릭터·스토리 생성(글 AI), 그림(NovelAI), 음성(Fish Audio), 음악(ElevenLabs)은 **각자 본인 키**를 넣어야 써요. 키 없이도 기본 게임은 다 할 수 있어요.
- 키는 **기기 안에만** 저장되고, 각 AI 회사 서버로 직접 요청할 때만 쓰여요(웹 버전에서 내 중계 서버를 켠 경우엔 그 서버를 거쳐요). 이 저장소나 제작자에게 전송되지 않아요.
- AI 사용 요금은 각 서비스 계정으로 청구돼요.

## 데이터
- 게임 데이터와 만든 그림은 기기(웹 버전은 브라우저) 안에만 저장돼요. 앱을 지우면 함께 지워지니, 설정 → 데이터 → 백업 파일 저장을 이용하세요.
- 수집하는 개인 정보는 없어요.

## 피드백
- 앱의 설정 → 공유와 피드백 → 피드백 보내기에서 복사해서 배포 게시글 댓글로, 또는 이 저장소 Issues로 남겨 주세요.
