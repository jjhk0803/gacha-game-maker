## 편집 화면

캐릭터 상세 → 일반 전투 스킬 편집·AI 생성에서 사용합니다.
효과 종류를 고르면 해당 효과에 필요한 배율 기준·타수·지연·간격·표식·중첩·상태 종류·스킬 슬롯 등의 입력칸이 표시됩니다.
효과별 대상, 우선순위, 추가 조건, 조건 기준값과 이름, 확률, 재적용, 소유권, 해제 가능 여부, 대상 소멸 시 처리를 설정합니다.
효과 순서를 위/아래 버튼으로 바꿀 수 있으며 자동 설명도 표시합니다.
연출 형태·색상, 필살기 수동 전용 설정도 반영합니다.

페이지의 「설계 내보내기」 JSON을 앱의 「스킬메이커 설계 파일 가져오기」에 붙여넣어 가져올 수 있습니다.
페이지는 행동 단위 대기시간을 사용했으므로 가져올 때 1행동=1.7초 기준으로 바꿉니다.
버스트만 구성한 슬롯이나 BURST 발동 패시브는 다른 효과·조건을 먼저 지정해야 합니다.
가져오기는 편집기에 채우는 작업이며 「검사하고 저장」해야 캐릭터에 반영됩니다.

## 전투 계산과 호환성

실제 전투와 내부 시뮬레이터는 동일한 core.js와 catalog.js를 사용합니다.
AI에도 같은 전체 카탈로그와 수치 형식을 전달합니다. 메뉴만 추가한 효과는 없습니다.
기존 version:2 저장의 배율은 변환하지 않고 유지합니다. 확장 효과에는 studio:true를 사용하여 백분율 수치 형식을 구분합니다.
기존 몹 난도 평가 결과는 새 계산 규칙으로 다음 준비 시 다시 검사합니다.
패시브 이벤트의 횟수, 쿨타임, 전투당 횟수, 최소 간격을 함께 적용하며 같은 틱 내 연쇄 발동은 제한합니다.

원본 시안의 공용 버스트와 행동 차례형 액티브는 복원하지 않습니다.
현재 게임의 액티브/필살기는 계속 초 기반입니다. 화면과 가져오기 안내에도 단위를 표시합니다.
스킬 대기 변화량도 초로 입력합니다.

안전한 계산 범위: 상태 최대 96개/유닛, 예약 효과 최대 256개, 한 효과 최대 30타, 최대 99표식,
보호막 합계 최대 자신의 최대HP, 최대HP 기반 보스 공격의 1타 최대 25%HP, 주 능력치 배율 0.2~3배.
HP 소모는 최소 1HP를 남깁니다. 수동 입력 수치는 저장 시 임의로 밸런스 조정하지 않습니다.
