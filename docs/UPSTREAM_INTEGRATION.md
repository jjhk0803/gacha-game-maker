- 공식 저장소: https://github.com/jjhk0803/gacha-game-maker
- 공식 main 및 최신 확인 릴리즈: `2026.10.16.2`
- 기준 커밋: `0cf37d029fb5ebb810531a67f0c3c0f088461e6e`
- 통합 대상: 개인 수정본 `2026.10.18.3`까지의 전투·스킬·장비·성장·UI 변경
- 최초 공통 기준: `v2026.10.14.7`

기존 HTML을 최신 HTML 위에 통째로 덮지 않고 Git의 공통 조상을 기준으로 3방향 병합했습니다. `www/index.html`·`version.json`·`www/sw.js`의 충돌을 해결했습니다. PC 서버 ZIP은 공식 최신 파일을 그대로 사용합니다.

## 보존한 공식 기능

게임 게시/구독과 진행 데이터 유지, 구독 게임의 플레이 전용 모드·자체 콘텐츠 생성 제한, 캐릭터 공통/세력 디자인 태그와 개별 제외, 이미지 삭제·프리셋 썸네일 삭제, 기존 그림을 재사용하는 게임 리롤과 참조 ID 이전, 초안 중복 문장 정리·되돌리기, IF/이격 로어 분리, BGM 일괄 생성·타이틀 음소거, 모바일 가로 넘침 방지 및 관계도/배포 페이지 버튼 구분을 유지합니다.

공식 추가·수정 비어 있지 않은 줄425개 중423개는 정확히 유지합니다. 두 줄은 플레이 모드 CSS의 스킬 편집 제한과, 새 게임 생성 프롬프트의 교본 명칭을 결합하여 유지합니다. 공식 최신 기능을 제거하는 충돌 해결은 하지 않았습니다.

## 기존 작업의 보존

세 슬롯 스킬·세대·조건부 액티브·개인 SP, 내부 검사, 연습장, 장비 고유 효과·변경 알림, 스킬 공통 레벨/전문화, 성장 비용3배·행동력240, 표시 기본 스탯으로 적용되는 탱커 강화, 도착/접촉 피해 판정과 전투 연출, 아이콘·스탠딩 설정을 보존합니다. 호감도는 기존대로 유지합니다.

`touchFace`·`faceSwap`·`petTick`·`charReact`는 공식 원문과 동일합니다. 오뚝이형 터치 반응 대안은 적용하지 않았습니다.

## 배포 구분

이 PR의 소스는 공식 제목·공식 업데이트 저장소·기존 공식 릴리즈 메타데이터를 사용합니다. 릴리즈 번호를 임의로 발행하지 않고 HTML 해시와 오프라인 캐시만 변경합니다. 관리자가 수락 후 새 릴리즈 번호를 정해야 합니다. 개인 테스트 APK는 `scripts/build-android-test.py --private-repo OWNER/REPO`로 생성할 때만 별도 채널을 활성화합니다. 따라서 이 PR용 ZIP을 개인 테스트 채널용 패치와 동일한 것으로 취급하면 안 됩니다.

## 검증

- 전체 자동 테스트209개 통과. 최신 기능과의 통합 검사6개를 추가했습니다.

- 전체 브라우저 검사의 강화 비용 예제를 새3배 비용에 맞췄습니다.
