# 일반 전투를 세 슬롯 스킬·개인 SP·스킬 성장과 연습장으로 개편

일반 전투에서 캐릭터마다 하나의 턴 기반 스킬과 BURST를 사용하던 흐름을 패시브·조건부 액티브·개인 SP 궁극기로 전환합니다. 제작자는 같은 규칙으로 스킬을 직접 편집하거나 선택한 슬롯만 AI로 생성하고, 실제 전투 엔진을 공유하는 내부 검사 및 연습장에서 결과를 확인할 수 있습니다.

공식 `main`의 `2026.10.16.2` (`0cf37d029fb5ebb810531a67f0c3c0f088461e6e`) 위에 통합했습니다. 게임 게시·구독, 디자인 공통 태그, 그림 재사용 리롤, 이미지 삭제, 초안 정리, BGM 개선 및 모바일 레이아웃 수정을 보존합니다. 터치 반응과 심연탐사 카드 전투는 이번 개편의 대상이 아닙니다.

## 주요 변경

- 패시브/액티브/궁극기 탭, 발동 조건에 맞는 입력 항목, 수동 최대5효과와 세대별 보수적 AI 생성(1~3효과), 선택 슬롯만 생성·실패 사유·중단·최대5회 재시도
- 시즌 운영의1~5세대 설정, 캐릭터 컨셉과 역할 중심의 생성 정책, 슬롯별 전력 예산 및 같은 전투 엔진을 사용하는 검사·과성능 약화
- 시간·평타·적중·피격 등의 액티브 조건, 공격/피격/지원 등으로 채우는 개인 SP 궁극기, 버튼 내부 SP 게이지와 시간형 액티브 대기 시간
- 근접 접촉과 투사체 도착 시 실제 피해 적용, 다단히트 궤적·각도, 의미별 연출과 미리보기, 시전자 표시, 궁극기 컷인·스피드라인·일시 전투 정지, Android 프레임 기반 재생 경로
- 설정의 연습장: 파티 편성,1~5마리 불사·비행동 허수아비, 일시정지/재시작 및 피해·회복 지표. 보상·소모·저장 편성에 영향 없음
- 패시브나 액티브 하나를 자동 선정하여 강화하는 장비 고유 효과, 편집·AI 생성, 연계 스킬 변경 시 중지와 빨간 경고, 장비 해금 버튼 보존
- 공통 스킬 Lv.1~7과 슬롯별 전문화3단계, 효과별 성장과 민감 효과 제한, 강화 전후 비교·비용 확인. 기존 장비 재료를 교본으로 전환하고 재고 보존
- 레벨업·돌파·장비·스킬 성장 재화3배, 최대 행동력240(회복5분/1 유지). 호감도·보상·성장 성능 유지, 기존 레벨·강화 단계 및 경험치 진행률 보존
- 높은 탱커 기본 HP/방어력과 기존 데이터의1회 이전. 역할에 따른 숨은 방어 배율 대신 표시 스탯과 계산을 일치
- 장비와 세 스킬의 개별 카드·스킬 아이콘 생성, 스탠딩 사용 선택과 상반신 대체, 도움말 말풍선

## 최신 기능과의 연결

게시 콘텐츠에 스킬·장비·스킬 아이콘·세대·스탠딩 설정을 포함합니다. 구독 업데이트는 기존 보유 캐릭터의 레벨·전문화·경험치·호감도·재화를 보존합니다. 구독 모드의 제작 제한과 시즌 자동 생성 제한을 유지하며 연습장은 사용할 수 있습니다.

공식 웹 소스에는 개인 저장소를 업데이트 대상으로 설정하지 않습니다. 공식 릴리즈 번호·APK URL은 관리자가 배포 시 결정하며, 이 PR은 공식 메타데이터를 유지하고 HTML 해시만 갱신합니다. 개인 테스트 채널은 `scripts/build-android-test.py --private-repo OWNER/REPO`로 별도 생성할 때만 활성화됩니다.

## 검증과 한계

`npm run build`, `npm test` 및 실제 Chromium 모바일 화면 검증을 수행합니다. 정확한 통과 수와 기준 커밋은 [최신 통합 검증](UPSTREAM_INTEGRATION.md) 및 `validation/upstream-integration.json`에 기록합니다. 스킬 생성 API와 게시/구독 네트워크는 모의 응답을 사용합니다. 실제 Android 기기·외부 AI 서비스·실제 GitHub 게시/구독 전송은 미검증입니다. 임의의 모든 수동 스킬 조합의 밸런스를 보장하지 않습니다.

스킬 엔진은 수정 가능한 `www/combat/` 모듈을 `npm run build`로 원본 단일 HTML에 포함합니다. 실행에 npm 의존성은 필요하지 않습니다. 검토는 `core.js`(계산), `generation.js`(생성), `bridge.js`/`effects.js`(UI·연출), `equipment.js`/`training.js`(성장), `tests/upstream-integration.test.cjs`(최신 버전 통합) 순으로 볼 수 있습니다.
