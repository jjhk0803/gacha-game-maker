# 역할 중심 스킬 생성 — 2026.10.16.9

프리코네의 기본 S1/S2/UB 사례에서 확인한 역할의 명확성, 짧은 연계, 효과 수와 실제 전력의 분리를 메이커용 생성 규칙에 반영했습니다. 모든 캐릭터를 출시 초기 OP 기준으로 전수 검증한 결과나 게임사의 공식 점수표를 구현한 것은 아닙니다. 수치 예산과 아래 상한은 메이커의 보수적인 설계값입니다.

## 세대별 AI 효과 수

| 세대 | 패시브 최대 | 액티브 최대 | 궁극기 최대 |
|---|---:|---:|---:|
| 1 | 1 | 1 | 1 |
| 2 | 1 | 1 | 2 |
| 3 | 1 | 2 | 2 |
| 4 | 2 | 2 | 3 |
| 5 | 2 | 3 | 3 |

최대 개수입니다. 높은 세대에서도 보조 효과가 없는 설계를 허용합니다. 패시브·액티브·궁극기 세 슬롯은 그대로이며, 표의 숫자는 각 슬롯 안에 붙는 효과 개수입니다. 수동 편집의 기존 효과·조건·발동 메뉴와 5개 상한은 유지합니다.

설정 → 시즌 운영에서 새 캐릭터의 세대를 고릅니다. 기존 캐릭터는 자기 출시 세대로 다시 생성합니다. 저장된 수동 스킬은 이 AI 상한에 맞춰 임의로 자르지 않습니다. 기존 자동 스킬은 새 규칙으로 자동 검사할 때 제한이 적용될 수 있습니다.

## 생성 과정

1. 앱이 캐릭터의 공격형/방어형/지원형 역할, 세대, 슬롯의 효과 상한과 전력 예산을 정합니다.
2. AI에게 복잡한 전투 JSON 전체 대신 이름·설계 종류(recipe)·보조 효과·상대 강도·발동 방식의 짧은 설계를 요청합니다. 사용자 컨셉과 기존 다른 두 스킬도 참고합니다.
3. 앱이 설계를 실제 엔진 효과로 변환합니다. 단위, 대상, 정수 횟수, 지속 시간, 기본값, 허용 범위를 채웁니다. AI가 수십 개의 세부 필드를 모두 정확히 작성할 필요가 없어졌습니다.
4. 역할·세대·중복 효과·중첩·범위 비용을 검사하고 수치를 보정합니다. 한 캐릭터가 공격·회복·보호막·SP를 한꺼번에 해결하는 설계를 제한합니다.
5. 같은 전투 엔진으로 모의 전투를 비교합니다. 편집기에서는 현재 선택한 슬롯만 초안으로 반환하고 저장 전에는 캐릭터에 적용하지 않습니다.

공격형은 단일/연속/전체 공격과 지속 피해, 방어형은 자기 방어·보호막·회복, 지원형은 회복·보호막·공격 지원 등을 중심으로 설계합니다. 보조 효과는 해당 주효과와 어울리는 목록에서만 선택합니다. 1~2세대의 고성능 피해 감소는 AI 메뉴에서 제외하고, 3세대 이후 탱커도 최대 8%로 제한합니다. SP 지원은 3세대 이후 지원형의 액티브에서 단일 아군에게 최대 10만 허용합니다. AI의 전체 SP 공급, 자기 환급 궁극기, 피해 기반 재증폭, 분신·변신·기록 연쇄는 제외합니다.

액티브는 평타/적중/피격/시간/체력 조건 등을 지원합니다. 피격은 탱커 중심, 치명타 발동은 3세대 이후로 안내하며 기본 횟수와 시간 간격도 캐릭터·스킬 이름에 따라 달라질 수 있습니다. 모든 캐릭터가 항상 서로 다른 순간에 발동한다는 보장은 없습니다. 궁극기는 기존 개인 SP 100 발동을 유지합니다.

## 생성 실패 처리

- 선택 필드 누락·숫자 형식·잘못된 범위는 앱의 기본값과 보정으로 처리합니다. 구형 effects 형식 응답도 계속 받아 줍니다.
- 생성 단계, 경과 시간, 각 시도의 실패 원인, 자동 보정 내역을 표시합니다.
- 최초 요청+최대 5회 재생성 뒤 멈춥니다. 편집기는 검증된 기본 설계의 **복구 초안**을 표시하고 사용자가 저장해야 적용합니다.
- 새 캐릭터 자동 구성도 같은 짧은 설계·검사 규칙을 사용합니다. 형식 실패가 계속되면 역할별 기본 설계를 적용하고 캐릭터 상세의 ‘최근 스킬 생성 기록’과 안내에 그 사실을 남깁니다. 이를 AI 성공으로 표시하지 않습니다.
- 인증·잔액·권한 오류는 즉시 중단하고 통신·시간 초과·요청 제한은 최대 3회 후 중단합니다. 이런 오류를 정상 AI 생성으로 가장하지 않습니다.
- 편집기와 새 캐릭터 생성 표시에는 중단 버튼이 있습니다. 취소 후 늦게 오는 응답은 적용하지 않습니다. 서버에 이미 전송된 요청은 서비스 측에서 처리될 수 있습니다.

## 전력 검사 수정

선택 슬롯을 비교할 때 다른 두 스킬은 후보와 기준 양쪽에서 동일하게 유지합니다. 다른 슬롯이 강하다는 이유만으로 이번 스킬을 계속 약화시키던 잘못된 비교를 수정했습니다. 세 스킬 전체를 생성하는 경우에는 전체 검사를 수행합니다.

정적 비용의 전체 대상 배수는 예전 일괄 2.8 대신 기준 인원을 명시했습니다: 아군 4명, 적 5명, 자신 외 아군 3명, 무작위는 설정 인원수입니다. 제한된 진영·속성·역할·표식 대상은 보수적인 추정 인원 4명을 사용합니다. studio 형식의 구형 강화/약화 별칭도 실제 지속 강화 비용을 적용합니다. 수치는 실측 점수표가 아니라 안전 검사이며 모의 전투와 함께 사용합니다. 전체 비용식은 SKILL_COST_REFERENCE.md에 있습니다.

## 검증과 테스트 설치

85개 자동 검사를 통과했습니다. 모의 AI 응답으로 짧은 설계, 구형 응답, 잘못된 숫자, 실패 후 재시도, 복구, 취소, 다른 슬롯 보존을 확인합니다. 역할·세대·설계 종류 조합도 검사합니다. Android 실기와 사용자의 실제 AI 설정으로 유료 호출은 수행하지 않았습니다.

새 APK는 기존 ‘메이커 전투 테스트’와 같은 앱 식별자와 테스트 서명을 사용하며 versionName 2026.10.16.9, versionCode 10입니다. 기존 테스트 앱 위에 업데이트 설치할 수 있도록 구성했습니다. 설정의 앱 업데이트 주소는 기존 개인 테스트 저장소를 유지합니다. 파일을 설치하기 전 앱 안의 내보내기로 저장 데이터를 백업할 수 있습니다.

깃허브 업로드 ZIP은 소스와 www/index.html, version.json을 포함합니다. ZIP을 풀고 최상위 포장 폴더 안의 파일·폴더를 기존 저장소 같은 위치에 올립니다. 자동 패치 대상은 main의 www/index.html이므로 Release에 APK만 추가하는 것으로 웹 코드가 교체되지는 않습니다.
