# 전투 애니메이션 재생 수정 — 2026.10.17.5

## 이번에 확인한 코드 문제

이전 버전은 기기에서 `prefers-reduced-motion`이 전달되면 전투 돌진·투사체 이동·컷인 이동·스피드라인을 생략했습니다. 전투 자체의 애니메이션 선택 메뉴도 없었습니다. 스피드라인은 길게 이어진 무늬를 약간씩 옮기는 표현이어서, 위치값이 변해도 실제로는 정지한 선처럼 보이기 쉬웠습니다.

이 두 경로는 코드와 재현 검사로 확인했습니다. 사용자의 실제 기기에서 어느 경로가 작동했는지는 아직 확인하지 못했습니다. 이전 브라우저 검사 결과만으로 Android에서 잘 보인다고 설명한 것은 검증 범위를 넘었습니다.

## 수정 내용

- 설정 → 화면·연출에 **전투 애니메이션** 메뉴를 추가했습니다. 기본값 **일반**은 돌진·이동 투사체·스피드라인을 재생합니다. **간소화**는 이동과 선을 생략합니다. **기기 설정에 맞춤**을 선택하면 기기의 동작 줄이기를 따릅니다. 사용자의 선택은 저장됩니다.
- 일반 모드에서는 시스템의 동작 줄이기 신호만으로 전투 이동과 스피드라인을 자동으로 없애지 않습니다. 웹 CSS에서도 일반 모드를 명시하면 선을 표시하도록 했습니다.
- Android 앱의 캐릭터 돌진, 스킬 투사체·적중·시전자 표시와 컷인은 **프레임마다 위치·크기·투명도를 직접 갱신**합니다. 애니메이션 API가 존재하는지만 확인하고 맡기는 경로를 사용하지 않습니다. 웹에서는 기존 기본 API와 대체 경로를 함께 유지합니다.
- 컷인 위아래에 각각 12개, 총 **24개의 짧은 선**을 넣습니다. 길이·굵기·간격을 달리한 선이 약 0.21~0.315초마다 화면을 반복해서 가로지릅니다. 위·아래의 이동 방향은 반대입니다. 긴 배경 무늬를 조금씩 옮기는 방식은 없앴습니다.
- 컷인 표시 순서를 올려, 직전에 사용한 스킬의 시전자 이름이 컷인 위로 비치는 문제도 수정했습니다.
- 큰 컷인 1.80초·작은 컷인 1.45초, 컷인 중 전투 정지, 일반 공격 몸통박치기, 시전자의 몸에서 출발하는 투사체, 전투 계산과 생성 밸런스는 유지했습니다.

## 설치 후 확인

1. `maker-animation-fix-2026.10.17.5.apk`를 기존 테스트 앱 위에 설치합니다. 앱 데이터는 지우지 않습니다.
2. 전투 화면 상단에 **테스트 2026.10.17.5**가 표시되는지 확인합니다.
3. 설정 → 화면·연출 → **전투 애니메이션: 일반**, **기술 컷인: 항상 크게**를 선택합니다. 컷인이 ‘끄기’면 선도 나타나지 않습니다.
4. 설정 → 연습장에서 궁극기를 사용합니다. 위아래의 짧은 선들이 계속 지나가는지 확인합니다. 검·방패 캐릭터의 근접 평타 돌진과 총·활·마법 캐릭터의 투사체도 함께 확인할 수 있습니다.

새 APK는 기존과 같은 패키지/서명을 쓰고 Android 업데이트 번호를 16으로 올렸습니다. 기존의 더 오래된 다운로드 패치가 새 설치 파일을 덮어 실행하지 않는지도 검사했습니다. 비공개 GitHub 자동 업데이트 주소는 유지합니다.

## 업로드 파일

`maker-animation-fix-upload-2026.10.17.5.zip`은 전체 소스입니다. 압축 내부 폴더의 **내용**을 저장소 루트에 반영합니다. 웹 자동 패치에는 `www/index.html`과 루트 `version.json`을 함께 반영합니다. APK 파일은 Release에 첨부할 수 있지만 APK 첨부만으로 저장소의 웹 파일이 갱신되지는 않습니다.

`maker-animation-fix-preview-2026.10.17.5.html`은 같은 스킬 연출기와 스피드라인을 사용하는 미리보기입니다. 실제 편성 전투와 Android 기기 성능 검사를 대신하지는 않습니다.

## 검증과 한계

자동 검사에는 게임의 일반/간소화/기기 따르기 선택을 확인하는 검사를 추가했습니다. 실제 Chromium 검사에서는 기기의 동작 줄이기를 켜고 기본 애니메이션 API를 사용할 수 없게 만든 조건에서 Android 재생 경로를 실행했습니다. 투사체의 실시간 좌표 변화와 시전자 표시, 24개 선의 반복 이동, 시간 차이를 둔 선 영역의 실제 이미지 변화, 컷인 정지·복귀를 확인했습니다. 단순히 애니메이션 요소나 변환값이 존재하는지만 검사하지 않았습니다.

최종 검사는 APK에서 추출한 HTML로 진행했습니다. 소스·APK·패치 HTML과 전투 모듈 일치, 기존 서명과 패키지 유지, 네이티브 DEX 보존도 확인했습니다. 실제 Android 기기의 설치·표시·성능은 아직 확인하지 못했습니다. 상세 결과는 소스의 `validation` 폴더에 포함합니다.
