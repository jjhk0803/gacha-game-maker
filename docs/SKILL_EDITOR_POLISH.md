# 스킬 편집·컨셉·공격속도 개선 — 2026.10.16.10

## 화면

- 작업 중단 버튼과 관련 안내는 생성/검사 중에만 보입니다. hidden 속성을 버튼 CSS가 덮어쓰지 못하게 처리했습니다.
- 사용자 화면의 ‘자동 액티브’를 ‘액티브’로 통일했습니다. 액티브의 자동 발동 방식은 그대로입니다. 이전 저장의 스킬 슬롯·피해 강화 문자열도 새 이름으로 이전하여 효과가 달라지지 않게 합니다.
- AI 효과 상한·슬롯별 전력 예산에 대한 긴 안내를 편집기와 시즌 설정에서 제거했습니다. 실제 생성 상한은 이전 버전과 같습니다.
- 효과의 적용 대상과 종류에 따라 사용되는 입력만 표시합니다. 자신/전체/고정 대상/무작위 대상에서는 불필요한 우선순위를 숨깁니다. 단일 적·단일 아군과 연쇄의 다음 대상 선택에서는 유지합니다.
- 즉시 피해·즉시 회복·SP 지원 등의 효과에는 지속 중첩·재적용·해제 설정을 숨깁니다. 지속 효과에서만 해당 설정을 표시합니다. 효과 소유권은 표식·기록·표식 참조 또는 아군에게 주는 지속 효과의 합산에 필요한 경우에 표시합니다.
- 표식/기록 계산 기준을 골랐을 때는 참조할 이름을 입력할 수 있습니다. 무작위 대상의 인원수(targetCount)와 해제할 상태 개수(count)를 분리했습니다. 기존 데이터는 과거 count를 대상 인원수로 이전합니다.
- 전투 시작/상시처럼 한 번 적용하는 발동 시점에서는 반복 대기·발동 횟수 제한 등 불필요한 입력을 숨깁니다. 숨긴 필드의 기존 값은 보관합니다.
- 인게임 효과 설명의 시간 단위를 실제 엔진과 같은 초로 표시하고, 요약에서는 불필요한 소유권·해제·대상 소멸 규칙을 생략합니다. 고급 설정에서 편집할 수 있습니다.

## 기본 공격속도

| 역할 | 기본 속도 범위 |
|---|---:|
| 공격형 | 105~111 |
| 방어형 | 77~83 |
| 지원형 | 83~89 |

캐릭터 이름·속성에 따라 범위 안의 값이 정해집니다. 재접속이나 스킬 재생성 때마다 무작위로 바뀌지 않습니다. 기존 캐릭터도 처음 불러올 때 한 번 조정하고 이전 속도는 별도 보관합니다. 이후 수동으로 바꾼 속도는 같은 역할에서 유지하며 역할 변경 시 새 역할 속도를 부여합니다. 새 캐릭터와 스탯 재생성에도 적용합니다. 내부 기준 파티의 속도도 같은 역할 기준으로 변경했습니다. 레벨에 따라 공격속도를 무조건 올리는 방식은 아닙니다.

기존 스테이지의 적 수치 자체를 일괄 변경하지는 않습니다. 몬스터 스탯 자동 조정 버튼을 사용할 때는 변경된 기준 파티로 검사합니다.

## 컨셉에 맞는 이름과 능력

AI가 프로필·사용자 컨셉·전용장비에서 모티프를 먼저 찾고 이름과 능력이 어울리는 이유를 설계하도록 요청합니다. 지원형 중 치유/치료/회복/의사/성녀 등의 설정이 있는 힐러에게는 자기 공격·치명타 강화 대신 아군 지속 회복·보호막 중심의 패시브 재료를 제공합니다. 힐러 패시브의 기본 발동은 시간 간격이며 공격 몇 회마다 자기 강화하는 구조로 만들지 않습니다.

이름에 조준·사격·저격 등이 있는데 캐릭터의 프로필·컨셉·장비에 총/활/사격 모티프가 없으면 컨셉 불일치로 재요청합니다. 불·얼음·암살 계열의 명확한 모티프 충돌도 검사합니다. 복구 초안도 캐릭터 설정에서 유래한 이름을 사용합니다. 사용자 컨셉은 저장 시 캐릭터에 보관하여 이후 생성에서도 참고합니다.

이 검사는 명확한 모티프 충돌을 잡는 규칙과 AI 지시를 조합한 것이며, 모든 문장의 의미를 완전하게 판정한다는 보장은 아닙니다. 수동으로 입력한 스킬 이름을 이 규칙으로 차단하지 않습니다.

## 같은 세대 기준 과성능 처리

선택 슬롯은 다른 두 슬롯을 동일하게 유지하고, 해당 캐릭터의 출시 세대에 맞는 기본 스킬과 비교합니다. 기존의 27개 조건(레벨 3개×전투 유형 3개×고정 난수 3개)은 유지합니다.

AI 생성 스킬이 강한 편(비교 비율 1.3 초과 또는 정적 예산 초과)이면 수치·지속시간·반복 간격을 약화해 최대 6회 모의 전투로 재검사합니다. 약한 스킬을 무조건 강화하는 처리는 하지 않습니다. 최초 비율·약화 횟수·최종 비율을 기록합니다.

그래도 강하면 AI에 같은 세대 기준의 비율과 약화 방향을 전달해 다시 설계합니다. 형식 오류·컨셉 오류·과성능 재설계를 합쳐 AI 요청은 최초+재생성 최대 5회, 총 6회입니다. 마지막까지 기준을 넘으면 같은 세대의 보수적인 기본 초안을 검사해 제시합니다. 그 초안도 기준을 넘으면 실패 사유를 표시하고 기존 스킬을 유지합니다. 강한 결과를 일반적인 생성 성공으로 저장시키지 않습니다. 편집기의 생성 결과는 사용자가 저장해야 반영됩니다.

새 캐릭터의 세 스킬 전체 검사도 약화·재검사와 기본 설계 복구를 사용하며 복구 사실은 캐릭터 상세의 생성 기록에 남깁니다. 수동 스킬은 검사만으로 임의 약화하지 않습니다. 기준 비율은 메이커의 근사 평가이며 모든 파티·적 조합의 강함을 보장하는 절대 점수는 아닙니다.
