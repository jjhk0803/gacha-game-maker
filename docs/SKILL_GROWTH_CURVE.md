## 적용 범위

- 직접 효과와 같은 의미의 능력치 강화/약화 형식 모두 같은 성장식을 사용합니다. 피해 감소는 '받는 피해 감소', 적 공격속도 감소는 '행동 속도 감소', 치명타 확률 증가는 '치명타 확률 강화' 형식도 포함합니다.
