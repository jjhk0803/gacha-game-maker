# 플레이모드 스킬 이미지·연출 선택 수정 · 2026.10.17.15

## 확인한 원인

플레이모드에서 '스킬 이미지 생성' 버튼은 보이지만 `www/combat/bridge.js`의 `v2OpenIcons`가 플레이모드이면 아무 안내 없이 종료했습니다. 이미지를 생성하기 전에 창 자체가 차단되는 문제입니다.

다단히트는 두 단계에서 선택값이 무시됐습니다. `www/combat/visual-catalog.js`가 다단히트·연쇄·분산·지연·표식 폭발을 직접 선택한 연출 적용 대상에서 제외했습니다. `www/combat/effects.js`의 타격 렌더러도 효과 분류가 다단히트이면 선택한 형태보다 참격을 우선했습니다. 연쇄와 분산의 투사체도 각각 번개·총탄을 강제했습니다. 특정 캐릭터의 손상된 저장 데이터가 없어도 이 코드 경로로 같은 종류의 증상을 재현할 수 있습니다.

## 수정

- 플레이모드에서도 스킬 이미지 창을 열고 기존 그림 AI 설정으로 생성할 수 있습니다. 이미지 확인·목록 반영·완료 저장·취소 폐기 흐름은 유지합니다. 스킬 능력 편집은 플레이모드에서 계속 차단합니다.
- '효과별 자동'일 때만 효과 종류가 기본 외형을 결정합니다. 직접 고른 연출은 다단히트·연쇄·분산·지연·표식 폭발에도 적용합니다.
- 타격 외형과 투사체 선택에서 자동 효과 분류가 수동 선택값을 덮어쓰지 않게 했습니다. 빙결창의 오래된 보조 참격도 제거했습니다.
- 회복 연출의 자동 고정, 추가 공격의 빛줄기 강제 지정도 직접 선택한 형태를 존중하도록 정리했습니다. 상태 표시 배지는 실제 효과 종류를 계속 보여 줍니다.
- 타수·대상·연쇄 순서·피해·회복 계산을 변경하지 않았습니다. 기존 .14의 성장식, 재료, 장비, 컷인 입장·퇴장 연출도 유지합니다. 연쇄 등의 타격 순서는 그대로이며 선택한 투사체의 이동시간에 맞춰 시각적 도착 시점은 달라질 수 있습니다.
- 편집→저장→다시 열기→미리보기→다음 전투의 설정 전달 경로도 검사합니다. 이미 진행 중인 전투는 시작 시 복사한 스킬을 사용하므로 편집 후 새 전투나 연습장을 시작해야 합니다.

## 검증 범위

전체 선택 가능 연출을 모든 효과 종류에 대입해 선택값 보존을 확인합니다. 다단히트·연쇄·분산·지연·표식 폭발의 연출만 바꾼 전투 결과를 비교해 계산이 동일한지도 검사합니다.
